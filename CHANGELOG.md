# Изменения

## 1.0.0

Первый выпуск.

- Виджет одним файлом `avai-chat.js`: веб-компонент `<avai-chat>` в Shadow DOM, без зависимостей в рантайме, со строгим
  CSP без `unsafe-inline` и `unsafe-eval`.
- Протокол шлюза v1.0: сессии, диалоги, долгий опрос ленты событий, история, загрузка картинок, оценка диалога,
  «печатает» и «прочитано».
- Повторы с тем же `client_msg_id` при обрыве связи, `5xx` и `429` (`Retry-After`), синхронизация вкладок, кэш ленты
  в `localStorage`.
- Хуки маскирования `beforeSend`, `afterReceive`, `beforeAttach` по принципу fail-closed; режим `requireHooks`.
- Неочищенный текст в браузере не хранится: свои сообщения — после `beforeSend`, ответы — после `afterReceive`; превью
  картинки — после `beforeAttach`. Имя файла посетителя на шлюз не уходит, метаданные картинок срезаются.
- `reset()` — новый посетитель: для выхода пользователя из аккаунта.
- Настройка атрибутами `data-*`, `window.AvaiChatConfig` и `configure()`; JS API `window.AvaiChat` с очередью вызовов
  до загрузки; события `ready`, `open`, `close`, `message`, `error`, `rating`, `proactive`.
- Внешний вид: CSS-переменные `--avai-chat-*`, `::part()`, слоты, тексты; полноэкранный режим на телефоне.
- Быстрые вопросы, подсказка у кнопки, автооткрытие, проактивные приглашения, аватары, звук и мигание заголовка вкладки.
- Безопасная разметка ответов: жирный, курсив, код, списки, ссылки только `http(s)`, `mailto`, `tel`.
- Ядро без интерфейса `avai-chat-core.js` с типами — для своего интерфейса.
- Сборка `npm run build`, значение для `integrity` — `npm run sri`. Лицензия MIT — `LICENSE`, сторонние компоненты — `THIRD-PARTY-NOTICES`.
